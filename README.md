# COVID-19 Power BI Global Analytics

## 📊 Project Overview

An interactive Power BI dashboard analyzing global COVID-19 cases, deaths, recoveries, testing, and pandemic trends across countries and WHO regions.

## 🎯 Project Objectives

- Analyze global COVID-19 cases and deaths
- Track active and recovered cases
- Analyze new cases, deaths, and recoveries over time
- Compare countries and WHO regions
- Identify the top affected countries
- Study the progression of the pandemic

## 📈 Dashboard Pages

1. **Landing Page**
2. **Executive Dashboard**
3. **Key Metrics**
4. **Global & Geographic Analysis**
5. **Top 10 Analysis**
6. **Pandemic Progression**

## 🛠️ Tools & Technologies

- Power BI
- Data Analysis
- Data Visualization
- DAX
- Interactive Dashboard Design

## 🔍 Key Insights

The dashboard provides a consolidated view of COVID-19 statistics and enables users to explore pandemic patterns across countries, regions, and time periods.
